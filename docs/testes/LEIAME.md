# Registro de testes do LUMNA

Um teste por linha em `registro.tsv`, mexido só pelo `teste.py` (rode sem argumentos para a ajuda). A página de acompanhamento sai de
`python3 teste.py pagina` (pasta `pagina/`) e é publicada como o artefato "LUMNA OS, testes". O jeito de trabalhar está em
`docs/areas/TESTES.md`. `importar.py` já foi usado uma vez (o roteiro antigo, `docs/TESTES-ISO.md`): não rodar de novo.
